# Swift bindings (generated — do not hand-edit)

Generated by **UniFFI 0.32** from `crates/kovanica-ffi/src/lib.rs`.
Regenerate after any FFI-surface change:

```bash
cargo build --release -p kovanica-ffi
cargo run -p kovanica-ffi --bin uniffi-bindgen -- \
    generate --library target/release/libkovanica_ffi.so \
    --language swift --out-dir crates/kovanica-ffi/bindings/swift
```

CI enforces byte-identical output (`.github/workflows/bindings.yml`).

## Consuming

1. On macOS, run [`build-apple.sh`](../build-apple.sh) to produce
   `target/kovanica.xcframework` from the static library (iOS arm64, macOS
   arm64 + x86_64). The framework embeds `kovanicaFFI.h` and
   `kovanicaFFI.modulemap` from this directory.
2. Add the xcframework to your Xcode project and compile `kovanica.swift`
   into the app target.

No external Swift runtime dependency: UniFFI 0.32 generates everything
inline, and the modulemap exposes the FFI symbols under module name
`kovanicaFFI`. If you bump the Rust `uniffi` crate version, regenerate both
languages and update this note — generated helpers must match the runtime.

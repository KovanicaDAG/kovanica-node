# Kotlin bindings (generated — do not hand-edit)

`uniffi/kovanica/kovanica.kt` is generated by **UniFFI 0.32** from
`crates/kovanica-ffi/src/lib.rs` (UDL-free proc-macro scaffolding). Regenerate
with the bundled helper after any FFI-surface change:

```bash
cargo build --release -p kovanica-ffi
cargo run -p kovanica-ffi --bin uniffi-bindgen -- \
    generate --library target/release/libkovanica_ffi.so \
    --language kotlin --out-dir crates/kovanica-ffi/bindings/kotlin
```

CI enforces this (`.github/workflows/bindings.yml`): a PR that changes the
FFI surface without regenerating fails with drift.

## Consuming

Use the Gradle module in [`../../android/`](../../android/) — it compiles this
tree plus `jniLibs/<abi>/libkovanica_ffi.so` (built by
[`build-android.sh`](../../build-android.sh)) into an AAR.

Runtime dependency (already declared in the module):

- `net.java.dev.jna:jna:5.14.0@aar` — UniFFI 0.32 generates JNA-based
  bindings; no other runtime artifact is needed. The inline helpers in the
  generated file must come from the *same* uniffi version as the Rust crate,
  so pin upgrades of both together.

Min SDK 24 (matches `--platform 24` in `build-android.sh`). R8 rules for the
consuming app ship in `android/consumer-rules.pro`.
